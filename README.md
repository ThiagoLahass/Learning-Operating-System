# Learning Operating System

Welcome to the "Learning Operating System" repository! This repository contains various materials and examples related to learning fundamental concepts in operating systems, such as inter-process communication, synchronization, memory management, and threading.


## Description of Directories

- **`Inter Process Communication/`**: Contains examples of inter-process communication, including FIFOs and pipes.
- **`Lab1_Files/`**: Files and examples from Lab 1, covering basic operating system concepts.
- **`Lab2_Files/`**: Files and examples from Lab 2, focusing on process creation and execution.
- **`Lab3_Files/`**: Files and examples from Lab 3, related to signal handling.
- **`Lab4_files/`**: Materials for Lab 4, including examples of shared memory.
- **`Process/`**: Examples of process management and communication.
- **`Prova1/`**: Exam files on process and signal concepts.
- **`Shared_Memory/`**: Code examples for shared memory management using `shmget` and `mmap`.
- **`Signals/`**: Examples and tests on signal management.
- **`Synchronization/`**: Examples of synchronization techniques, including semaphores and mutexes.
- **`Threads/`**: Examples and tests on thread management and synchronization.

## How to Use

1. **Clone the Repository**: Clone the repository to your local machine:
   ```bash
   git clone https://github.com/ThiagoLahass/Learning-Operating-System
   ```

2. **Explore the Directories**: Navigate through the directories to find code examples and lab materials.

3. **Compile and Run**: Use `makefile` where available to compile the examples. Execute the files as needed to test and experiment.
